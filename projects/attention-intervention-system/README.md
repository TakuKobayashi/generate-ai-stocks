# Attention Intervention System (AIS)

「必ず目に入る場所に目標を書いて貼る」習慣をAndroidスマートフォンで実現するアプリです。

## 主な動作

- 1日最大3件の目標を登録できます。
- 目標を公開通知として常駐させ、端末のロック画面と通知欄に表示します。
- Hardモードでは、画面ONを検知して目標カードを短時間オーバーレイ表示します。
- 端末再起動後も通知、毎日の更新予約、Hardモードの監視を復元します。
- 目標は1日1回だけ編集でき、安易な書き換えを防ぎます。

## Android上の制約

ロック画面への表示はAndroidの公開通知を利用します。端末側でこのアプリの「ロック画面の通知」を非表示にした場合や、通知内容を隠す設定にした場合は表示されません。Hardモードのオーバーレイはロック解除後を含む画面ON時の補助表示であり、OSのセキュアなロック画面自体を置き換えるものではありません。

初回起動時に通知権限を許可してください。Hardモードでは、追加で「他のアプリの上に表示」権限が必要です。

## ビルド

Android Studioでプロジェクトを開くか、Gradle Wrapperを使ってビルドします。

```sh
./gradlew assembleDebug
```
